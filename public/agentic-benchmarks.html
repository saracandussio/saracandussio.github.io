Agentic reasoning benchmarks, by tier

Each tier adds one source of information the prompt doesn’t contain. Click a row to see one item taken from that split’s data files: the task as stored, the tools, the reference the dataset keeps (gold calls, oracle actions or answer) and how it’s scored. Every split has an item from the data.

Evaluation

TierBenchmarkSplitUnitsHopsEvaluationTags

Hops count dependent calls, where one call’s output is the next call’s input. “Parallel” means several independent calls. Units counts the items behind each row (tasks, questions, scenarios or rounds); hover or read the small print for how they relate to the benchmark total. Tags are free-form labels for what each row tests and can be searched. A tag under the tier (e.g. 0↔1, 1↔2, 2↔3) marks a split whose information source sits between two tiers or mixes them.

Evaluation families: answer (forced-answer curves work directly), state (needs rollouts with state restore at each cut), action match (fits commitment on which tool and which arguments), LLM judge (judge noise adds up across cuts), decision (only the call / ask / refuse choice is scored).
